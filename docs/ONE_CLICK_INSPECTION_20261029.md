# 一键返回、地图到达与巡检

本地 Qt 和网页共用 `/patrol/inspect_point`、`/patrol/return_home` 及原有巡航状态机，不重复启动导航、相机、云台或识别节点。

## 首次准备

1. 本地切换到定位导航模式，在启动前启用“路线巡航联锁”，启动原有导航流程，确认定位、Nav2、急停解除和联锁反馈就绪。
2. 在“路线巡航 → 地图与返航设置”登记并确认当前活跃地图。车辆在待命位置停稳后点击“当前位置设为返航点”。返航点按地图及版本保存；地图更新后须重新确认并保存。
3. 到点巡检需要已启动的相机、云台和识别服务。临时目标选择相机中已有的预置位；已有巡检点沿用保存的预置位、识别要求和多视角拍摄设置。

## 本地 Qt

- 工具栏或导航面板点击“一键到达与巡检”。巡检窗口中也可从顶部“一键到达”进入。
- 地图左键按住并拖动选择目标和到达朝向；滚轮缩放，Shift + 拖动平移。也可输入 X、Y、朝向，或选择已有巡检点。
- 点击“到达并巡检”：自主规划、到点停稳、执行拍摄识别、保存结果与报告。取消勾选“到达后抓拍识别”时只导航到点。
- 选择已有点位时以 ID 和版本请求，执行器使用点位原始完整精度及全部拍摄视角；改动坐标则成为临时目标，不写回点位或路线。
- 主窗口顶部和巡检窗口都有“一键返回”。巡检页面“取消当前任务”和主窗口取消按钮也支持尚在等待受理的到点/返回请求。

## 网页

- 正常运行 Qt，关闭本地“启用操作”并在网页取得控制权。
- 监控台地图上方点击“一键到达与巡检”，或使用右侧同名面板；选择已有点位或地图目标与朝向，然后点击“到达并巡检”。
- 顶栏“一键返回 / 取消返回”在监控、任务、记录页始终可用。右侧巡检面板和任务页保留返回入口。
- 无有效待命点、地图版本不符、急停未解除、状态过期或没有控制权时，返回按钮禁用并说明条件。顶栏显示返回的受理、取消、完成及错误反馈。

## 任务切换行为

一键返回会结束当前路线或到点巡检；确认旧任务及 Nav2 子目标终止后，才向待命点派发新目标。抓拍或识别服务已经收到的请求不能撤回，但取消后丢弃迟到回复、不再执行后续巡检步骤。取消返回、急停、失联或本地接管后，不自动恢复旧任务。

已有任务时拒绝另一个到点任务，连续点击返回不会重复提交。临时目标要求当前地图及版本、合法有限坐标和地图范围，定位、安全联锁及规划可达性由原执行器与 Nav2 检查。地图中的障碍和不可达区域不会因“一键到达”绕过检查。

## 更新及验证

本次没有修改 ROS 接口或机器人硬件配置。原有安装版本须包含 `InspectPoint` 和 `ReturnHome`；构建本地 Qt 后重新打开，网页强制刷新即可加载新入口。未安装巡航接口的旧环境先按 `web/README.md` 构建业务包。

验证使用独立 ROS 域、临时地图、假 Nav2/相机/识别及本机浏览器服务，不启动实车驱动。覆盖地图旋转原点与拖动朝向、已有点位版本、地图更新失效、取消未受理请求、重复返回、识别等待中返航，以及网页跨页返回与失联处理。实车路径和相机效果仍需现场验收。
