# RS485 双轴巡航修复与协议核验（2026-10-25）

入口：`desktop_ui/scripts/run.sh` → 设备执勤 → 云台巡航。

## 协议核验

依据根目录 [RS485 球机坐标设置与查询协议说明](../../RS485球机坐标设置与查询协议说明.pdf)，已逐页核对：

| 项目 | 文档定义及当前实现 |
| --- | --- |
| 串口 | RS485、8N1、地址 1；文档标称 9600bps，本机实测 2400bps |
| 帧格式 | `FF Add Cmd1 Cmd2 Data1 Data2 Sum`，Sum 为地址到 Data2 累加取低 8 位 |
| 水平查询 | `FF 01 00 51 00 00 52`，回复命令 `59`，二进制角度除以 100 |
| 俯仰查询 | `FF 01 00 53 00 00 54`，回复命令 `5B`，二进制角度除以 100，超过 180° 后减去 360° |
| 水平/俯仰设置 | 命令 `4B` / `4D`；负俯仰以 360° 回绕编码 |
| −9° 设置 | 原始值 35100，即 `0x891C`；帧为 `FF 01 00 4D 89 1C F3` |
| +15° 设置 | 原始值 1500，即 `0x05DC`；帧为 `FF 01 00 4D 05 DC 2F` |
| Z 查询 | 正确帧为 `FF 01 00 55 00 00 56`；PDF 的末字节 `54` 不符合其校验规则 |
| Z 单位 | 文档为二进制原始值 / 100，范围 1～20×；本机 Z=0，无效，镜头继续使用已验证的 SDK 网口通道 |

本次只读核验：9600bps 下 X/Y/Z 均无回复；2400bps 下收到 `FF 01 00 59 05 D1 30`（水平 14.89°）、`FF 01 00 5B 01 F6 53`（俯仰 5.02°）和 `FF 01 00 5D 00 00 5E`（Z=0）。这些 2400bps 回复的地址和校验均正确，因此没有按文档标称值直接更改现机波特率。

PDF 要求收到查询应答后再发送下一条，避免半双工冲突。串口读写共用递归锁；本机实测运动帧还需与上一次有效回复间隔至少 120ms，否则可能被设备忽略。该间隔也用于绝对坐标写入。

PDF 说明的是坐标读写；连续运动方向通过实机验证：`04` 左、`02` 右、`08` 使本机有符号俯仰减小、`10` 使其增大。双轴使用按位组合的连续方向帧，并分别设置水平、俯仰速度。

## 修复

- `/ptz/control_patrol` 提供独立的 RS485 双轴控制，默认俯仰 −9°～+15°，水平速度 2 档、俯仰速度 1 档。启动前读取实际角度，范围外先定位到最近端点。
- 轮询使用独立回调组和双线程执行器。串口读取及收发间隔不再阻塞每 200ms 一次的续租；500ms 看门狗仍然保留。
- 俯仰在接近端点时减速，并保持减速状态到换向，避免速度反复跳变；反馈距端点不超过 0.1° 时换向，水平速度保持不变。
- 停止时先取消旧巡航，再等待串口发送停止。旧轮询任务在读回后和发送运动前检查巡航身份，不能在停止确认后重新启动运动。停止失败继续重试。
- 巡检暂停时保存俯仰方向，恢复后继续原方向，避免在中间位置提前换向。巡检取消、租约失效、角度反馈无效或持续不变时保持停止。
- 巡航中的 `/ptz/get_angles` 使用新鲜的实际采样，避免额外查询挤占总线；镜头变倍仍走 SDK 网口。

## 验证

协议和节点回归在隔离 ROS 域 226 使用模拟硬件；实机验证在域 227 使用真实串口、驱动和巡航节点，不涉及底盘运动。两类验证分开记录，不能用模拟测试代替实机结论。

自动化回归共 45 项通过，包括 PDF 帧及负角度编码、SDK 镜头、串口恢复、无效反馈、端点减速、读串口超过租期时继续续租、读串口期间停止、巡检暂停/恢复、人工取消和失联停止。`ptz_pelco`、`chassis_nav2` 已构建并安装。

自动化命令：

```bash
source /opt/ros/humble/setup.bash
source ros2_ws/install/setup.bash
ROS_DOMAIN_ID=226 ROS_LOCALHOST_ONLY=1 \
  PYTHONPATH="$PWD/ros2_ws/src/ptz_pelco:$PYTHONPATH" \
  python3 -m pytest -q ros2_ws/src/ptz_pelco/test
```

现机详细结果见 [实机验证记录](rs485_patrol_verification_20261025.json)。本次验证的参数为水平 2 档、俯仰 1 档、俯仰范围 −9°～+15°、单侧水平扫掠 6 秒；其他速度组合未逐一实机验收。

- 连续实际采样约 35.5 秒，观测俯仰范围 **−8.90°～+14.95°**。三个换向反馈依次为 **+14.91°、−8.90°、+14.95°**，水平同步往返五段，全程无异常续租超时。
- 实际巡检暂停后，间隔 0.5 秒两次读回俯仰均为 6.78°，水平变化 0.04°；释放后继续向俯仰减小方向运动。
- 正常停止后，间隔 0.5 秒两次读回俯仰均为 14.97°，水平变化 0.09°。
- 主动停止续租后，约 **0.522 秒**完成驱动自动停止；间隔 0.5 秒两次读回俯仰均为 12.09°，水平变化 0.09°。
- 验证后停止并恢复测试前水平 **14.89°**、俯仰 **5.02°**；测试进程退出，不自动开启执勤。

重新执行 `./desktop_ui/scripts/run.sh`，在设备执勤页启动云台巡航即可加载已安装的驱动。独立启动的旧 `ptz_pelco` / `ptz_patrol` 进程也需要重启。
