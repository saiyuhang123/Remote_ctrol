# 全上位机视觉改造与验证

日期：2026-10-19。实施前检查点：`1fdac25`，**阶段检查点：完善控制界面与巡航并保存视觉改造草稿**。本轮在该检查点之后完成全上位机视觉方案，并补齐 ROS2 可执行入口安装配置和启动回归测试。

## 当前交付

| 功能 | 当前实现 |
| --- | --- |
| 人脸检测、小图 | OpenCV YuNet；只检测和裁图，不比对姓名、身份或是否登记；连续可见默认每 2 秒留图 |
| 行人检测 | YOLO26n OpenVINO CPU，COCO person 类；适配端到端 `[1,300,6]` 输出 |
| 车牌检测 | OpenCV Zoo LPD-YuNet，独立于行人模型；原图四角点定位、透视矫正 |
| 车牌号码 | 只加载 HyperLPR3 字符 ONNX 模型；归一化牌照比例，接受 7/8 位及置信度门槛，同轨迹同号码连续两帧确认 |
| 独立启停 | 复用同一检测节点，按三类参数加载/释放模型；只开人脸不加载行人或车牌模型，只开车牌不运行 YOLO |
| 图片与坐标 | 沿用本地 SQLite/JPEG、历史 TF、地图标记、无定位照常保存图片、无效坐标明确标记 |
| Qt / 网页 | 人脸开关指向上位机 `enable_face`；网页无需海康人脸状态或抓拍服务，模型故障时仍可关闭功能 |

旧海康 SDK 人脸接收在 Qt 启用检测时尝试关闭；记录节点默认不订阅或补扫原生海康人脸，旧的已归档历史保留。相机只提供视频，三类检测均需要持续取流。三个功能不绑定导航、巡航、车辆操作许可、急停解除或云台动作，支持车辆静止执勤。

本次同时清理了视觉测试与文档中已被网页只读改造移除的后台写接口假设，没有恢复旧写入 API。当前后台只读巡检摘要，完整独立抓拍通过 Qt 历史或本地 CLI 查询；`upload_enabled` 保持默认 false。

## 使用步骤

1. 结束旧 Qt，再运行 `./desktop_ui/scripts/run.sh`。若检测/记录是外部终端启动的旧版本，也需由操作者结束后重新启动；Qt 不终止外部节点。
2. 打开右侧 **抓拍识别 → 独立视觉执勤**。
3. 点击 **启动上位机人脸**；或者勾选“行人 / 车牌”，点击 **启动行人 / 车牌**。可以同时启用三类。
4. 等待模型就绪且显示“视频已接入”，目标进入画面后在 **查看视觉记录** 中筛选、刷新并查看小图。
5. 需要小车坐标时，先有实际有效定位，再在历史窗口关联对应地图标记。没有定位时图片正常保存，坐标无效。
6. **停止人脸检测**只关闭人脸；**停止上位机检测**关闭三类推理，已入队记录允许保存完成，历史查询继续可用。

默认最多 4 次推理/秒、CPU 线程数 2，实际频率取决于耗时。切页、隐藏面板或关闭历史不停止检测。状态和历史是结果入口，未增加每次识别弹窗或预览叠框。

## 模型与环境

新模型已写入 `ros2_ws/src/detector_node/models/` 并安装到 ROS 包；文件大小、SHA-256、来源和许可证见 [模型清单](../ros2_ws/src/detector_node/models/README.md)。运行环境不需要 PyTorch、Ultralytics 或 HyperLPR3 Python 包，字符模型不在启动时下载。

YOLO26n 在独立 venv `~/.cache/robot_vision_export` 导出，使用现有 OpenVINO 2024.6.0 转换，不升级 ROS Python 的 NumPy。运行侧保持 NumPy 1.26.4、transforms3d 0.4.2、OpenCV 4.10.0、ONNX Runtime 1.23.2。FAST-LIO 使用的 `tf_transformations` 导入验证通过。

## 2026-10-19 启动入口修复

实机点击“启动上位机人脸”报退出码 1，复现为 `ros2 run detector_node detector` 返回 `No executable found`。原因是 `detector_node` 缺少 `setup.cfg`，console_script 被安装到 `install/detector_node/bin`，而 ROS2 从 `lib/detector_node` 发现可执行程序。之前的直接 Python 实例与模型测试没有覆盖这个安装入口。

已补齐 ROS2 标准脚本安装目录并重新构建安装；`ros2 pkg executables detector_node` 能列出 `detector_node detector`。新增隔离测试通过真实 `ros2 run` 子进程启动仅人脸模式，确认收到 YuNet ready / face=true 的状态，且行人、车牌保持关闭。测试使用域 227 与临时 staging，不接触实际相机或业务记录。当前 UI 无需重编译或重启，可直接重新点击启动按钮。
